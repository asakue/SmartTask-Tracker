# SmartTask Tracker 🎯

Умный трекер задач с аналитикой, канбан-доской, календарём и таймером Pomodoro.

## 🚀 Возможности

- **Авторизация** — регистрация и вход с JWT-токенами
- **Управление задачами** — CRUD, приоритеты, статусы, теги, подзадачи
- **3 представления** — Список, Канбан-доска, Календарь
- **Аналитика** — графики продуктивности, распределение по приоритетам и категориям
- **Pomodoro таймер** — фокус-сессии с привязкой к задачам
- **Тёмная и светлая тема** — переключение одной кнопкой
- **Адаптивный дизайн** — работает на мобильных и десктопе

## 📦 Технологии

- **Frontend:** Next.js 15 (App Router), React 19, Tailwind CSS
- **Backend:** Next.js API Routes
- **База данных:** SQLite + Prisma ORM
- **Аутентификация:** JWT (jsonwebtoken + bcryptjs)
- **Стейт-менеджмент:** Zustand
- **Графики:** Recharts
- **UI:** shadcn/ui-стиль компоненты, Lucide React иконки

## 🛠 Установка и запуск

### Предварительные требования

- Node.js 18+ 
- npm или yarn

### 1. Клонирование и установка зависимостей

```bash
cd "SmartTask Tracker"
npm install
```

### 2. Настройка окружения

Файл `.env` уже создан. При необходимости измените:

```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="ваш-секретный-ключ"
JWT_EXPIRES_IN="7d"
```

### 3. Инициализация базы данных

```bash
npx prisma db push
```

Это создаст базу данных SQLite и применит все миграции.

### 4. Запуск сервера разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 5. (Опционально) Studio для базы данных

```bash
npx prisma studio
```

Откроется веб-интерфейс для просмотра и редактирования данных.

## 🔐 API Endpoints

### Аутентификация
| Method | Endpoint | Описание |
|--------|----------|----------|
| POST | `/api/auth/register` | Регистрация нового пользователя |
| POST | `/api/auth/login` | Вход в систему |
| GET | `/api/auth/me` | Получить профиль текущего пользователя |
| POST | `/api/auth/logout` | Выход из системы |

### Задачи
| Method | Endpoint | Описание |
|--------|----------|----------|
| GET | `/api/tasks` | Получить все задачи (с фильтрами) |
| POST | `/api/tasks` | Создать новую задачу |
| GET | `/api/tasks/:id` | Получить одну задачу |
| PUT | `/api/tasks/:id` | Обновить задачу |
| DELETE | `/api/tasks/:id` | Удалить задачу |

### Аналитика
| Method | Endpoint | Описание |
|--------|----------|----------|
| GET | `/api/analytics` | Получить аналитику пользователя |

### Фокус-сессии
| Method | Endpoint | Описание |
|--------|----------|----------|
| GET | `/api/focus` | Получить фокус-сессии |
| POST | `/api/focus` | Создать фокус-сессию |
| PUT | `/api/focus/:id` | Обновить сессию |
| DELETE | `/api/focus/:id` | Удалить сессию |

> Все endpoints кроме регистрации и входа требуют JWT-токен в заголовке `Authorization: Bearer <token>`.

## 🎨 Использование

### Создание задачи
1. Войдите в систему
2. Перейдите в раздел "Задачи"
3. Нажмите "Новая задача"
4. Заполните название, описание, приоритет, дедлайн и теги
5. Добавьте подзадачи при необходимости

### Канбан-доска
- Переключитесь на вид "Канбан" для управления задачами по статусам
- Меняйте статус задач кнопками в карточках

### Календарь
- Задачи с дедлайнами отображаются в сетке календаря
- Кликните на задачу для редактирования

### Аналитика
- Процент выполнения задач
- Продуктивность по дням недели
- Распределение по приоритетам и категориям
- Серия дней (streak) продуктивности

### Pomodoro таймер
- Выберите режим: Фокус (25 мин), Короткий перерыв (5 мин), Длинный перерыв (15 мин)
- Привяжите сессию к конкретной задаче
- Таймер автоматически переключается между режимами
- После 4 фокус-сессий — длинный перерыв

## 📱 Адаптивный дизайн

Приложение полностью адаптивно:
- **Мобильные устройства** — боковое меню скрывается, появляется кнопка "гамбургер"
- **Планшеты** — оптимизированная сетка
- **Десктоп** — полное боковое меню со всеми функциями

## 🔒 Безопасность

- Пароли хешируются через bcrypt (10 rounds)
- JWT токены с истечением (7 дней по умолчанию)
- Все API endpoints защищены middleware авторизации
- Изоляция данных: каждый пользователь видит только свои задачи
